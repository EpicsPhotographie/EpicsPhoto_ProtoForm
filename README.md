# Epics Photographie - Zone Concours

Ce projet est une démonstration d'une page HTML statique pour l'organisation d'un concours photo.  
Il utilise HTML/CSS/JS de base, et un service tiers sécurisé (EmailJS) pour la soumission du formulaire.  

**Aucune donnée personnelle n'est stockée localement.**  
L'adresse e-mail utilisée est celle du photographe pour recevoir des participations.

---

## Objectifs
- Formulaire de participation à un concours photo
- Affichage d’un logo, fond personnalisé
- Envoi via EmailJS

## Démo
Le site peut être visualisé via GitHub Pages après activation.

## Avertissement
Ce projet est uniquement à but éducatif et professionnel, sans intention frauduleuse.
